# 一舟的小作品 · 公开分享版

五个免登录、可直接在浏览器中使用的小作品，部署到 GitHub Pages。

- **沙间**：落沙、雨水、土壤下渗、种树与燃烧。
- **星引**：拖拽发射星球、轨道、碰撞、轨迹与双指平移缩放。
- **数据小画室**：粘贴表格，绘制三种图表，选择三套风格，导出 PNG / SVG。
- **观点整理板**：拖动卡片、连接论点与材料、导出提纲、备份恢复。
- **时间账本**：计时、补记、每日分布、目标、CSV 与 JSON 备份。

## 公开版的数据

无需 GPT 或 GitHub 账号。观点与时间记录通过 IndexedDB 保存在访问者自己的浏览器中，不上传，不跨设备同步。浏览器清理网站数据或使用临时/无痕窗口时，记录可能无法保留。重要内容请使用各工具的备份导出功能。

此项目仅包含前端；原账号版仍使用独立的认证与云端数据。这里没有迁移任何账号版记录。

## 运行和构建

Node.js 22.13+，`npm ci`，`npm run dev`。构建：`npm run build`。

- 分享入口：`/`
- 沙间：`/sand-garden/`
- 星引：`/orbit-play/`
- 工具室：`/studio/#data`、`/studio/#ideas`、`/studio/#time`

GitHub Pages 使用 `gh-pages` 分支的根目录，构建产物中的相对资源路径兼容项目子目录。

保留使用到的界面样式依赖许可证于 `vendor/`。
